# Task 06 — devPromptReader views comparison

## Modes

1. vue épurée = text only (no chrome decoration)
2. carrousel auto = auto-advance sections/pages
3. vue décorée = themes, bars, extras

## Steps

1. Open same URL in each mode.
2. Compare readability: line length, contrast, distraction.
3. Prefer default = épurée for long text; décorée optional; carrousel for short cards only.

## Decision rule

IF long article → default text-only
IF feed cards → carousel allowed
IF user chose theme → decorated
