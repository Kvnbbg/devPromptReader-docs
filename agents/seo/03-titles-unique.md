# Task 03 — Unique titles and descriptions

## Goal

Each priority URL has unique title and meta description.

## Priority URLs

- /
- /hub or /hub.html
- /world.html
- /feed
- main tool pages linked from home
- recent article pages

## Rules

- Title: one clear topic + brand if short enough
- Description: 1–2 sentences, benefit, no duplicate paste
- One h1 per page, matches topic

## Steps

1. List current title per URL.
2. Flag duplicates.
3. Propose or apply unique title + description.
4. Keep language formal and short.

## Do not

- Do not use keyword stuffing.
- Do not remove existing useful content.

## Output

URL | TITLE | DESCRIPTION | UNIQUE=yes|no
