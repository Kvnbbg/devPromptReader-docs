# AGENTS INDEX — find docs fast (low / tiny models)

## How to use

1. Read this file first.
2. Open only the pack path you need.
3. Inside a pack: README → ORCHESTRATOR → one task file.

## Ready-to-use code (no compile)

**`components/`** — vanilla ES modules: soft-notice, boosters, chronos-lives, hospital-state, integrate, example-usage.html

## Packs

| Need | Path |
|------|------|
| **Runnable JS components** | `components/` |
| SEO Google host/titles | `agents/seo/` |
| Math Lab / Money Quest / chronos / vies | `agents/game/` |
| Notification throttle | `agents/notify/` |
| Boosters design + code | `agents/boosters/` |
| Hospital / medical MMORPG (MatrixCitizen) | `agents/matrix-hospital/` |

## Keywords → path

component, integrate, soft-notice, no build → `components/`  
hospital, trauma, urgence, médecin, RP, MatrixCitizen → `agents/matrix-hospital/`  
throttle, notification → `agents/notify/`  
booster → `agents/boosters/` + `components/boosters.js`
