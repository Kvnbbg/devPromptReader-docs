# 08 — Language Register and Progressive Disclosure

## Register

Interface and documentation copy employ a formal academic style consistent with Harvard semantic conventions:

- Precise, defined terminology.
- Logical hierarchical structure.
- Claims supported by the preceding formal model or explicit design decision.
- Absence of colloquialisms, casual expressions, and emoji.

## Progressive Disclosure

Language and feature exposure progress from simple operational guidance for novice users to precise technical exposition for expert users.  
Technical internals remain hidden behind explicit progressive disclosure mechanisms (expandable sections, secondary panels, advanced mode toggles).

## End-User Language Levels

- **Simple**: concise action-oriented instructions sufficient for immediate use.
- **Intermediate**: brief explanations of parameters and consequences.
- **Expert / Academic**: full formal description of underlying models, integrity guarantees, and architectural invariants.

The same principle governs the documentation itself: each successive page increases technical density while remaining readable in isolation after the mandatory prior pages have been studied.

Having reached this page, the reader has completed the required sequential study of the design documentation.

Implementation actions may now be undertaken, provided they remain strictly within the constraints defined across the preceding pages and preserve the non-destructive, symbiotic character of the project.
